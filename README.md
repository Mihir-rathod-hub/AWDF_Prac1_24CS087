# Personal Developer Portfolio

A responsive personal developer portfolio website built with React, Vite, JavaScript, and modern CSS.

## Features
- **Component Architecture**: Modular and reusable components (`Header`, `About`, `Skills`, `Projects`, `Footer`).
- **Responsive Design**: Clean layout optimized for desktop, tablet, and mobile viewing.
- **Styling**: Bluish-purple and white color palette with custom CSS.
- **Fast Build**: Powered by Vite and React 19.

## Tech Stack
- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (CSS Grid, Flexbox, Custom Properties)
- **Code Quality**: Oxlint

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
